# ClassHelm · 课堂领航

[官网及三端下载](https://classhelm.kicp.fun/) · [0.1.23公开测试发行](https://github.com/0810Kevin/classhelm-releases/releases/tag/desktop-2026-10-22-r2)

免费、公开、免登录下载安装包。本仓库只分发安装包、更新包、校验值与公开说明，应用源码不在此仓库。

教师端支持Mac和Windows；学生端优先Windows 10/11，自动识别Intel/AMD 32/64位；独立校长巡课端支持Mac和Windows。学生端不支持Windows ARM64，Win7兼容需另验。

0.1.23修复设备移动显示与后续改名保存，按首次绑定顺序排列；减少无变化时的课堂通信；增加同密钥证书续期与长期配对连续性；学生端加入课外自动更新，新版教师端内置学生更新包，也支持选择本项目签发的`.chupdate`更新包。

0.1.22及更早学生端须先安装一次0.1.23基础版。基础版开机后自动检查新版，在没有课堂进行时验签、升级并保留配对、维护密码及本机规则；网络不可用则继续运行当前版本。C盘还原软件可能撤销更新：基础更新程序必须先保存到还原基线中，之后可在开机时自动补更新。本项目不关闭或替换还原软件，不承诺跨磁盘还原永久保存。

课堂功能包括教学网站限制、网页打开、课堂锁定、倒计时、可见提示的屏幕查看和教室概览。巡课只有查看权限，不接管教师。仅用于经机构授权的设备，不提供隐蔽监控。

本批为公开测试版：双架构编译、协议回归、包内文件与更新签名核验已完成；Windows后台升级／回滚、冰熊重启恢复及真实整班负载仍需现场验收。安装包尚未完成机构代码签名及Mac公证。签名不增加课堂功能，主要影响系统发布者识别和安装信任；安全拦截请交管理员审查，不要关闭系统防护。

Windows双击Setup安装，Mac打开DMG拖入Applications。升级前保存工作、结束课堂，不先卸载或清空配置。学生卸载需管理员确认，先恢复策略与注销服务；恢复失败停止卸载并保留恢复工具。卸载会保留授权、密码、规则及恢复文件，不属于零残留删除。

GitHub下载速度受网络影响。下载后可用发行中的`SHA256SUMS.txt`核验文件。更新包有本项目发布验签，区别于商业代码签名，不能据此宣称安装包已获Microsoft或Apple认证。
