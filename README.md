# ClassHelm · 课堂领航

[官网及三端下载](https://classhelm.kicp.fun/) · [1.0.10 内测版](https://github.com/0810Kevin/classhelm-releases/releases/tag/v1.0.10-beta.1)

免费、公开、免登录下载。本仓库仅分发安装包、签名更新包、校验值和说明，应用源码及运行配置不公开。

教师端与独立只读巡课端支持Windows x64、Mac Apple Silicon和Intel；学生端支持Windows Intel／AMD 32／64位，安装器自动选择，优先Windows10／11，不支持Windows ARM64。

1.0.10修复更新失败恢复与教师端课堂重新加入，新增任务管理器维护密码入口、139域默认网页黑名单及默认开启的U盘读取开关。覆盖升级保留原身份、配对及自定义规则；旧版功能包括网页前置、卡片排序、教学资源依赖及主动寻找原教师IP。冰熊电脑仍需将新版程序和有效配对保存入还原基线。

U盘开关位于学生端维护设置，修改需维护密码；未建立密码时暂不写入限制。仅限制可移动磁盘读取，不修改写入策略及学校既有更严格设置；更改后需安全弹出重插，必要时重启。真实Windows设备与另存为兼容尚待核对，不覆盖所有USB设备。任务管理器经ClassHelm密码入口放行5分钟；CMD/PowerShell与编程软件不限制。

支持教学文件发送（PDF、Word等，单文件最多20MB）和确认后的正常关机。文件默认保存在当前学生桌面，同名另存、不自动打开；未保存内容提示可能阻止正常关机。巡课只查看，不具备课堂控制、文件或电源权限。查看有可见提示，不录像、不默认保存画面。

学生在课外自动获取、验签更新；已因旧版更新失败而停服的电脑需先覆盖安装本版恢复，保留原配对／规则／密码。教师／巡课发现新版后提示，点击一键更新，课堂和看屏结束后安装重开。正常升级保留原身份、配对、分组、网站、密码和规则。0.1.23及更早教师／巡课首次仍需从官网下载覆盖一次，之后使用内置更新；0.1.23学生基础版可后台升级，更早无更新能力的学生端需先安装一次基础版。

已预留签名更新源迁移，未来可以自动转向对象存储；当前继续GitHub。迁移时需让设备至少收到一次可信迁移信息。C盘还原环境需先将基础更新程序保存到还原基线，之后开机可以再次补更新，不承诺跨还原永久保存。

Windows双击Setup，Mac打开DMG拖入Applications。升级前保存工作、结束课堂并停止查看，不先卸载或清配置。学生卸载需Windows管理员权限和本机维护密码，验证后恢复策略和注销服务，取消验证不继续停服；完整Windows管理员仍可从系统层面修改文件，失败保留恢复入口；默认保留授权、规则、密码和日志，不属于零残留清理。

本批为内测发行。此前单机升级、受控失败回退和任务管理器功能已有测试反馈；不代表本批所有Windows原生升级、U盘、冰熊、真实整班及Win7／32位兼容性均已验收。安装包尚未完成机构代码签名和Mac公证，系统拦截交管理员审查，不关闭防护。更新包验签不等于Microsoft／Apple认证。GitHub下载速度和可达性受网络影响。

下载后可按发行附件中的SHA256SUMS.txt核验。教师／巡课更新通道为desktop-update-feed.json，学生更新通道为update-feed.json；其中的安装包仍验证发布签名。
